Aplicación desarrollada en Java que simula el funcionamiento de una plataforma de pedidos de comida rápida. El proyecto fue desarrollado con el objetivo de poner en práctica y consolidar conocimientos de Programación Orientada a Objetos (POO), estructuras de datos, manejo de arrays, lógica de programación y organización de código.

La aplicación permite al usuario interactuar con un sistema de pedidos completo, desde la creación de una cuenta y el inicio de sesión hasta la selección de productos, gestión del carrito y simulación de una compra.

FUNCIONALIDADES
-Registro e inicio de sesión de usuarios.
-Visualización e interacción con un menú de comidas.
-Selección de diferentes categorías y productos.
-Gestión del carrito de compras, permitiendo agregar y administrar productos.
-Simulación del proceso de compra.
-Registro y administración de tarjetas de crédito/débito.
-Registro y gestión de direcciones de entrega.
-Gestión de la información asociada a cada usuario.
-Validaciones y control de las distintas operaciones realizadas dentro de la aplicación.

CONOCIMIENTOS APLICADOS
Durante el desarrollo del proyecto se aplicaron diferentes conceptos fundamentales de Java, entre ellos:
-Programación Orientada a Objetos (POO).
-Clases, objetos, atributos y métodos.
-Encapsulamiento.
-Relaciones entre clases.
-Manejo de arrays y estructuras de datos.
-Estructuras de control y lógica de programación.
-Métodos y modularización del código.
-Validación y manejo de datos.
-Manejo de diferentes entidades y relaciones dentro de una aplicación.
-Resolución de problemas mediante algoritmos.

TECNOLOGIAS
-Java
-Programación Orientada a Objetos
-Arrays y estructuras de datos

INTERFAZ
El proyecto actualmente funciona mediante una interfaz de consola, sin interfaz gráfica (GUI). La interacción se realiza a través de diferentes opciones y menús que permiten simular el flujo completo de un usuario dentro de una plataforma de pedidos.

OBJETIVO DEL PROYECTO
El objetivo principal fue desarrollar una aplicación que permitiera llevar los conocimientos teóricos de Java a un proyecto práctico, simulando un escenario de uso real y trabajando con múltiples entidades, relaciones y operaciones.
Este proyecto forma parte de mi proceso de formación como Analista Programador Universitario y representa una aplicación práctica de los conocimientos adquiridos en programación y desarrollo de software.
